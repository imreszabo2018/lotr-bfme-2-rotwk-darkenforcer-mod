# The Lord of the Rings: The Battle for Middle-earth II: The Rise of the Witch-king - Dark Enforcer Mod

This project started with a simple idea: to take the gameplay framework of The Lord of the Rings: The Battle for Middle-earth II – The Rise of the Witch-king and use it as a foundation for something entirely new.

The mod introduces a new type of Custom Create a Hero and gameplay elements that are not part of Tolkien's world. While the project is built around the mechanics and visual language of The Battle for Middle-earth II, its new content is driven by original ideas and its own creative direction.

Install:

The mod runs with the original version of the game.


1. On your desktop, search for "The Lord of the Rings, The Rise of the Witch-king"

2. Right-click your new shortcut and select Properties.

3. Go to the Shortcut tab. In the Target box, you will see the file path wrapped in quotation marks 
(e.g., "C:\EA\The Lord of the Rings, The Rise of the Witch-king\lotrep2.exe").

4. Add the mod parameter: Click at the very end of the text in the Target box, press the Spacebar, 
type -mod followed by another space, and then type the exact name of your mod's folder or .big file
Something like:
D:\Games\rotwk\lotrbfme2ep1.exe -mod "D:\Games\darkenforcer"

5. Save changes: Click Apply and then OK

6. Launch the game
